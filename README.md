# CSE Speak

MASTER PROJECT PROMPT — CSE Professional English Learning Platform

1. PROJECT TITLE

Build a complete, modern, interactive web application called:

"CSE Professional English"

Tagline

Learn English. Speak Confidently. Grow Professionally.

The platform is specifically designed for CSE/IT students from 2nd year onward who want to improve their professional English for interviews, coding discussions, presentations, emails, meetings, LinkedIn, resume writing, client communication, and public speaking.

The platform should focus on:

Practical English > Grammar-heavy Learning

Do NOT make the application feel like a traditional grammar-learning website.

2. PROJECT OBJECTIVE

Create a structured 6-month professional English learning platform where students spend approximately 1 hour every day learning and practicing English.

The platform should help students progress from basic communication to professional and technical communication.

The complete learning journey should cover:

Listening

Speaking

Reading

Writing

Pronunciation

Interview preparation

Public speaking

The final goal is:

A CSE student should be able to confidently speak and write English in real academic and professional situations.

3. CORE LEARNING PHILOSOPHY

Implement the following 10 principles throughout the platform.

Rule 1 — Grammar Comes Later

Learning order:

Listening → Speaking → Reading → Writing → Grammar

Do not start the platform with Tenses, Voice, Narration, etc.

Grammar should only be introduced when it helps the student communicate better.

Rule 2 — Consistency Over Intensity

Encourage:

1 hour every day

instead of:

5 hours once a week

Implement daily streaks and consistency tracking.

Rule 3 — English Is a Language, Not a Subject

The platform should encourage students to actually use English.

Example:

Learning Java requires coding.

Learning English requires speaking.

Rule 4 — Mistakes Are Progress

Create a positive learning environment.

Do not make students afraid of mistakes.

Show progress such as:

Day 1 → Many mistakes
Day 15 → Fewer mistakes
Day 30 → Better confidence

Feedback should be constructive and encouraging.

Rule 5 — Daily Translation Practice

Provide approximately:

20 Hindi → English sentences every day

Use realistic situations instead of random textbook sentences.

Rule 6 — Shadowing Technique

Every day provide approximately:

15 minutes of shadowing practice

Flow:

Watch/listen to the speaker.

Pause.

Repeat the sentence.

Try to match pronunciation and rhythm.

Continue.

Include a shadowing timer.

Rule 7 — Learn Sentences, Not Isolated Words

Avoid teaching:

Create = Banana

Instead teach:

I want to create a website.

Vocabulary should always be taught using context.

Rule 8 — 10 Words × 3 Sentences

Daily vocabulary target:

10 new words

For every word:

3 practical example sentences

Rule 9 — Think in English

Add daily "Think in English" exercises.

Examples:

I am brushing my teeth.

I am going to class.

I am opening my laptop.

I am working on my project.

Rule 10 — Daily Speaking

Students should speak every day.

Possible methods:

Mirror speaking

Self-talk

Prompt speaking

Mentor practice

Peer practice

Voice recording
